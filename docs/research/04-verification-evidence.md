# 운임 비교 및 데이터 출처 재검증

확인일: **2026-10-25 (한국시간)**. 검토 기준: `ea5cfbb`의 프로토타입과 제안서. 이 문서는 공식 출처에서 확인한 사실, 예시 데이터에 둔 가정, 아직 확인하지 못한 범위를 기록한다. 소프트웨어 실행 결과와 실제 화주 견적 검증은 별도 증거가 필요하다.

## 1. KCCI와 비교할 금액

**확인한 사실.** KOBC 공식 KCCI 페이지의 [표준기술서](https://kobc.or.kr/ebz/common/file/KCCI_Standards.pdf) **2쪽 「01 운영 방식」의 ‘기준·단위’, ‘운임내역’**을 렌더링하여 확인했다.

| 구분 | 공식 기준 |
|---|---|
| 선적·계약 | 부산항 선적, 해상 수출 SPOT 운임 |
| 통화·장비 | USD, 전 항로 40ft Dry Container |
| 포함 | Ocean Freight와 BAF, CAF, LSS, EBS 등 운임성 할증료 |
| 제외 | THC, DOC Fee, WFG, Seal 등 현지 부대요금(Local Charge) |
| 예외 | 중국·일본 항로의 도착지 지불 비용 제외 |

따라서 별도 기재된 운임성 할증료가 O/F에 아직 포함되지 않았다면 함께 더한 금액을 KCCI와 비교해야 한다. 전체 견적 합계에는 현지 부대요금도 들어가지만, 그 합계를 KCCI 비교값으로 사용하지 않는다.

**기존 코드의 오류.** `prototype/app.js`는 첫 `OF` 항목만 찾아 비교했다. 예시 B에는 별도의 LSS 120달러가 있어 비교 금액이 작게 계산됐다.

| 예시 B 계산 | 금액 | KCCI 북유럽 3,475달러 대비 |
|---|---:|---:|
| 기존: O/F만 | 4,600달러 | +32.37% |
| 수정 기준: O/F 4,600 + 별도 LSS 120 | 4,720달러 | **+35.83%**; 정수 표시 +36% |

**예시 데이터에 둔 가정.** A·C의 O/F에는 비교에 필요한 운임성 할증료가 이미 포함되었거나 별도 청구되지 않는 것으로 둔다. B의 LSS는 O/F에 포함되지 않은 별도 금액으로 둔다. 이는 가상 견적을 계산하기 위한 가정이며, 실제 견적에 대한 검증 결과가 아니다. 실제 문서에서는 포함·별도 여부를 먼저 확인해 이중 합산을 막아야 하며, 그 확인의 자동화는 미구현이다.

**확인하지 못한 내용.** 이번에 확인한 공식 표준기술서와 데이터 설명에는 포워더 마진이 반드시 제외된다는 근거가 없다. “KCCI에는 포워더 마진이 없다”는 단정은 사용하지 않는다. 지수와 견적의 차이가 곧 부당 청구를 뜻한다는 해석도 하지 않는다. +10%, +25% 진단 경계는 프로토타입의 설정값이며 공식 적정운임 기준이 아니다.

## 3. 공공데이터 ID와 이용 조건

공식 상세 페이지와 DCAT XML의 `dct:title`, `dct:rights`를 함께 확인했다. XML 스냅샷은 아래 상대 링크에 보관한다.

| ID | 확인한 자료 | 판정 |
|---|---|---|
| [15131881](https://www.data.go.kr/data/15131881/fileData.do) | 한국해양진흥공사_컨테이너선운임지수(KCCI) | KCCI 출처가 맞다. 무료, 이용허락범위 제한 없음. [XML](evidence/data-go-15131881.xml) |
| [15133134](https://www.data.go.kr/data/15133134/fileData.do) | 해양수산부_해운항만물류정보_화물보안료산출정보 | **기존 제안서가 공표운임 자료로 잘못 인용했다.** 운임공표 데이터의 이용 조건을 입증하지 않는다. [XML](evidence/data-go-15133134.xml) |
| [15029607](https://www.data.go.kr/data/15029607/openapi.do) | 해양수산부_화물운임공표정보 | 공식 대체 출처를 확인했다. 무료, 이용허락범위 제한 없음. [XML](evidence/data-go-15029607.xml) |

15029607 공식 페이지의 **‘설명’, ‘API 유형’, ‘데이터 포맷’, ‘이용 조건 및 라이선스 정보’**에는 공표번호·항구코드 등을 입력해 공표일, 업체명, 적하·양하 항구, 통화·요금 정보를 조회하는 REST/XML API로 기재되어 있다. 개발·운영단계 자동승인 안내도 있다. 15133134는 화물보안료 산출을 위한 신고 자료이며, 선사 공표운임·요금표와 같은 자료가 아니다.

**확인 수준을 구분한다.** 15029607의 제공 명세와 이용 조건은 확인했다. 활용신청·인증키를 사용한 실제 API 호출, 필요한 부대요금별 필드와 항로의 충족 여부, 자료의 최신성·결측·완전성, 서비스 적재는 확인하지 않았다. 따라서 “데이터 출처와 이용 조건 확인”까지 표현하고 “실데이터 연동 완료” 또는 “필요한 모든 요금 확보”로 표현하지 않는다. 프로토타입의 부대요금 범위는 계속 예시값이다.

KCCI 15131881의 공식 설명에는 공표운임 25%와 패널 운임 75%가 기재되어 있다. 상세 페이지 ‘기타 유의사항’은 KOBC Timeseries에서 시작일을 2022-11-07로 바꾸고 Download를 누르면 주간 시계열을 XLS로 받을 수 있다고 안내한다. 취득 경로 확인과 실제 수집·갱신 구현은 별개다.

## 4. 확인 방법과 기록

- KOBC 표준기술서 PDF, KCCI 표 HTML, 공공데이터 DCAT XML 3종을 공식 URL에서 HTTP GET으로 내려받았다.
- 표준기술서 2쪽은 이미지로 렌더링해 위 포함·제외 범위를 읽었다. PDF의 본문이 이미지로 되어 있어 텍스트 추출 결과만으로 판단하지 않았다.
- XML을 파싱해 데이터 제목과 권리 필드를 확인했다. 검색 결과의 제목만으로 데이터셋을 확정하지 않았다.
- 제한된 검색으로 공표운임 자료를 찾은 뒤 15029607 공식 페이지와 XML을 직접 확인했다. 공표운임 API의 실제 응답은 이번 검증에 포함하지 않았다.
- 다운로드 시각, HTTP 상태, 바이트 수, SHA-256은 [검증 기록](evidence/source-checks-2026-10-25.json)에 남겼다. XML 원본만 저장소에 보관하며 PDF·HTML 전체는 복제하지 않았다. 동적 페이지를 나중에 다시 받으면 응답 해시가 달라질 수 있다.

이 근거는 기준값·비교 범위·데이터 출처의 정정에 사용한다. 진단 정확도, 화주의 이해도, 비용 절감, 실제 문서 추출 성능을 검증한 결과로 사용하지 않는다.

## 5. 코드 수정의 재현과 검증 (2026-10-25)

[회귀 테스트](../../tests/prototype.test.cjs)는 실제 `data.js`와 `app.js`를 Node.js의 최소 DOM 스텁에서 실행한다. 기존 코드에서는 **14개 중 11개 실패**, 수정 후에는 **14개 모두 통과**했다.

| 수정 | 재현 및 확인 |
|---|---|
| 운임성 할증료 포함 | B의 비교값 4,600 → 4,720달러. BAF·CAF·EBS 포함, KRW 할증료의 USD 환산, 할증료로 110% 경계를 넘는 경우를 검사했다 |
| 현지 부대요금 제외 | THC를 바꿔도 KCCI 비교값은 같고 견적 총액만 바뀐다. A·C 기존 총액도 유지됐다 |
| 입력값과 계산값 일치 | 기존에는 -1과 10000000000이 화면에 남지만 내부 값은 0과 1000000000이었다. 같은 상·하한을 화면에도 적용했다. 값의 범위는 기존 데모 설정을 유지한 구현 선택이다 |
| URL 샘플 키 검증 | 기존 `?q=constructor`, `?q=toString`, `?q=__proto__`는 상속 속성을 샘플로 읽어 실패했다. 실제 샘플 키만 허용하고 그 외에는 A를 연다 |

```sh
node --test tests/prototype.test.cjs
node --check prototype/app.js
node --check prototype/data.js
git diff --check
```

위 검사들은 통과했다. 별도로 로컬 브라우저에서 B의 **4,720달러·+36%·총액 6,864,500원**, 진단 근거와 메모 갱신, THC의 음수·상한 초과 입력 보정, `?q=constructor`의 A 화면 복귀를 확인했다. 이는 예시 데이터의 소프트웨어 동작 검증이다.

부대요금은 실제 공표 요금이 아직 연결되지 않아 **예시 요금 범위**라고 표시한다. 경고는 최댓값 초과가 아니라 **범위 중간값의 110% 초과**이므로 제목도 그 기준을 명시했다. 이 임계값은 공식 자료에서 정한 적정 요금이나 법적 허용 범위가 아니다.

기획서의 [A](../proposal/img/screen-a.png), [B](../proposal/img/screen-b.png), [C](../proposal/img/screen-c.png) 캡처를 수정본으로 갱신했다. 캡처 도구가 등장 애니메이션의 중간 프레임을 저장하는 문제를 피하기 위해 **임시 복사본의 `.row`, `.findings .quote` 애니메이션만 비활성화**했다. 데이터·계산·레이아웃은 동일하며 실제 앱의 CSS는 바꾸지 않았다. 입력·URL 회귀는 애니메이션 설정을 바꾸지 않은 원본 로컬 앱에서 확인했다.

변경은 로컬 작업 트리에만 반영했다. 커밋·푸시·재배포, 실제 공표 API 호출, 실견적 검수, LLM 연동 및 실제 사용자 성과 검증은 이번 결과에 포함하지 않는다.

## 6. 실제 API 연동 시도 (2026-10-30)

- 15029607 상세 페이지의 명세에서 호출 주소 `https://apis.data.go.kr/1192000/CychgFrghtOut4/Info4`와 요청변수(ServiceKey, pageNo, numOfRows 최대 50, annNo, annGb, annDeFr, annDeTo, fermnDeFr, fermnDeTo, shipngPrtCd, landngPrtCd 등)를 확인했습니다. 응답 항목에는 OF, BAF, CAF, LSS, EBS, OTHC, DTHC, 서류발급비, D/O, 부두사용료, 봉인료와 각 통화가 있습니다.
- Preview 배포에서 Vercel에 등록된 인증키로 부산(KRPUS)에서 로스앤젤레스(USLAX), 로테르담(NLRTM) 구간을 호출했습니다. 두 호출 모두 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(등록되지 않은 서비스키, 코드 30)를 받았습니다. 따라서 공표운임의 실제 응답, 항로 충족 여부, 최신성은 아직 확인하지 못했습니다.
- 같은 Preview에서 OpenAI 견적 읽기는 붙여넣은 가상 견적 1건(7개 항목)을 구조화했습니다. `BAF incl.`은 포함으로, `Handling at cost`는 금액 없음과 확인 필요로 표시되었고 금액을 만들어 내지 않았습니다. 한 건의 시연이며 추출 정확도를 검증한 결과는 아닙니다.
