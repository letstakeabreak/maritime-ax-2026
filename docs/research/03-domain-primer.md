# 도메인 입문: 해상 수출 견적서 읽는 법

R(중소화주 해상운임 견적 진단)을 이해하는 데 필요한 최소한만 정리했다. 기획서를 쓰다 막히면 이 문서로 돌아온다.

## 등장인물

| 역할 | 하는 일 | R에서의 위치 |
|---|---|---|
| 화주(수출기업) | 물건을 보내는 회사 | **사용자.** 견적을 받고 고른다 |
| 포워더(국제물류주선업자) | 화주 대신 선사 예약, 서류, 통관, 내륙운송을 묶어 판다. 선사 운임에 자기 마진과 부대비용을 얹는다 | 견적서를 보내는 쪽 |
| 선사(정기선사) | 배를 운항한다. 운임과 요금을 PORT-MIS에 공표할 의무가 있다 | 공표 요금이 비교 기준이 된다 |
| KOBC(한국해양진흥공사) | 해운 정책금융, 그리고 KCCI 운임지수를 발표한다 | 중립적인 운임 기준을 가진 공공기관 |

## FCL과 LCL

- **FCL(Full Container Load):** 컨테이너 1개를 통째로 빌린다. 운임은 컨테이너당(20ft, 40ft)으로 매긴다. KCCI와 비교할 수 있다.
- **LCL(Less than Container Load):** 다른 화주와 컨테이너를 나눠 쓴다. 운임은 CBM(부피)당으로 매기고, CFS(혼재 창고) 비용이 붙는다. 국내 공개 지수가 없다.
- 업계에서는 약 15 CBM 아래면 LCL이 유리하다고 본다.

## 견적서의 구조

견적은 크게 **해상운임**과 **부대비용**으로 나뉜다.

| 구분 | 대표 항목 | 성격 |
|---|---|---|
| 해상운임 | O/F(Ocean Freight) | 시장에 따라 크게 출렁인다. KCCI가 이것을 추적한다 |
| 할증료 | BAF, LSS(저유황유할증료), CAF, PSS(성수기) | 선사가 붙인다. 공표 대상이 일부 포함된다 |
| 출발지 부대비용 | THC(터미널 작업비), DOC(서류발급비), Wharfage(부두사용료), Seal, CFS(LCL만) | 금액이 비교적 고정되어 있다. 선사 공표 요금과 비교할 수 있다 |
| 포워더 수수료 | Handling, EDI, AMS/ENS(목적지 신고) | 포워더마다 다르다. 이름만 다른 중복 청구가 생기기 쉽다 |
| 육상과 통관 | 내륙운송(트럭킹), 통관수수료 | 지역과 거리에 따라 다르다 |
| 나중에 생기는 비용 | Demurrage, Detention(반납 지연료), 창고료 | **견적에 빠져 있다가 청구된다** |

## 화주가 당하는 전형적인 상황 (R이 짚어 줄 것)

1. O/F가 시장보다 비싼지 모른다 → KCCI 권역 운임과 비교해 위치를 보여 준다.
2. 같은 성격의 수수료가 이름을 바꿔 두 번 붙는다(DOC, EDI, Handling) → 중복 의심으로 표시한다.
3. 견적에는 없던 비용이 인보이스에 나타난다 → 누락 가능 항목을 미리 알려 준다.
4. 쓸 수 있는 지원사업을 모른다(중소기업 55.1%가 몰라서 안 씀) → 물류바우처, 지자체 수출물류비를 안내한다.

## 기준 데이터

| 데이터 | 내용 | 한계 |
|---|---|---|
| KCCI | 부산발 13개 권역 항로, 40ft당 달러, 매주 월요일 발표. 공표운임 25%와 패널 75%를 반영 | 권역 단위다. 포워더 마진과 부대비용은 포함되지 않는다 |
| 선사 공표운임 (PORT-MIS) | 모든 항로의 운임 288종과 요금 8종. 연 4회 공표 | 신고 기준이라 실제와 다를 수 있다. 수입 화물은 제외된다 |

## 용어 빠른 표

| 용어 | 뜻 |
|---|---|
| TEU / FEU | 20ft / 40ft 컨테이너 1개 |
| B/L | 선하증권. 선적했다는 증명서 |
| D/O | 화물인도지시서 (수입 쪽) |
| Incoterms (FOB, CIF 등) | 운송비를 누가 어디까지 내는지 정한 조건. FOB 수출이면 해상운임은 바이어가 낸다 |
| 장기운송계약 | 화주와 선사가 1년 단위로 운임을 고정하는 계약 |
