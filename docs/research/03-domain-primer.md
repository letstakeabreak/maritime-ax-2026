# 도메인 입문: 해상 수출 견적서 읽는 법

R(중소화주 해상운임 견적 진단)을 이해하는 데 필요한 최소한만 정리했다. 기획서를 쓰다 막히면 이 문서로 돌아온다.

## 등장인물

| 역할 | 하는 일 | R에서의 위치 |
|---|---|---|
| 화주(수출기업) | 물건을 보내는 회사 | **사용자.** 견적을 받고 고른다 |
| 포워더(국제물류주선업자) | 화주 대신 선사 예약, 서류, 통관, 내륙운송을 묶어 판다. 선사 운임에 자기 마진과 부대비용을 얹는다 | 견적서를 보내는 쪽 |
| 선사(정기선사) | 배를 운항하고 운임과 요금을 공표한다 | 실제 공표 요금의 적용 범위를 검증한 뒤 비교 기준으로 사용할 계획이다 |
| KOBC(한국해양진흥공사) | 해운 정책금융, 그리고 KCCI 운임지수를 발표한다 | 중립적인 운임 기준을 가진 공공기관 |

## FCL과 LCL

- **FCL(Full Container Load):** 컨테이너 1개를 통째로 빌린다. 운임은 컨테이너당(20ft, 40ft)으로 매긴다. KCCI와 비교할 수 있다.
- **LCL(Less than Container Load):** 다른 화주와 컨테이너를 나눠 쓴다. 운임은 CBM(부피)당으로 매기고, CFS(혼재 창고) 비용이 붙는다. 국내 공개 지수가 없다.
- 업계에서는 약 15 CBM 아래면 LCL이 유리하다고 본다.

## 견적서의 구조

견적은 크게 **해상운임**과 **부대비용**으로 나뉜다.

| 구분 | 대표 항목 | 성격 |
|---|---|---|
| 기본운임 | O/F(Ocean Freight) | KCCI 비교 시 별도 청구된 포함 할증료와 합산한다. O/F에 이미 포함된 금액은 다시 더하지 않는다 |
| 할증료 | BAF, CAF, LSS(저유황유할증료), EBS, PSS(성수기) | KCCI 공식 산출 기준의 포함 항목은 BAF, CAF, LSS, EBS다. 다른 항목은 포함 여부를 확인해야 한다 |
| 출발지 부대비용 | THC(터미널 작업비), DOC(서류발급비), Wharfage(부두사용료), Seal, CFS(LCL만) | THC, DOC, WFG, Seal Charge는 KCCI 제외 항목이다. 실제 공표 요금 비교는 데이터 적용 범위 확인이 필요하다 |
| 포워더 수수료 | Handling, EDI, AMS/ENS(목적지 신고) | 포워더마다 다르다. 이름만 다른 중복 청구가 생기기 쉽다 |
| 육상과 통관 | 내륙운송(트럭킹), 통관수수료 | 지역과 거리에 따라 다르다 |
| 나중에 생기는 비용 | Demurrage, Detention(반납 지연료), 창고료 | **견적에 빠져 있다가 청구된다** |

## 화주가 당하는 전형적인 상황 (R이 짚어 줄 것)

1. 운임이 시장에서 어디쯤인지 모른다 → O/F와 별도 청구된 KCCI 포함 할증료를 합쳐 권역 운임과 비교한다. 시점, 장비, 수량, 포함 비용의 차이도 확인해야 한다.
2. 같은 성격의 수수료가 이름을 바꿔 두 번 붙는다(DOC, EDI, Handling) → 중복 의심으로 표시한다.
3. 견적에는 없던 비용이 인보이스에 나타난다 → 누락 가능 항목을 미리 알려 준다.
4. 쓸 수 있는 지원사업을 모른다(중소기업 55.1%가 몰라서 안 씀) → 물류바우처, 지자체 수출물류비를 안내한다.

## 기준 데이터

| 데이터 | 내용 | 한계 |
|---|---|---|
| KCCI | 부산발 13개 권역 항로, 40ft당 달러, 매주 월요일 발표. 공표운임 25%와 패널 75%를 반영 | O/F와 BAF, CAF, LSS, EBS 포함. THC, DOC, WFG, Seal Charge 제외. 포워더 마진의 일률적 제외는 확인하지 못했다 |
| 화물운임공표정보 API (15029607) | 공표번호와 항구코드로 업체, 항구, 통화, 요금정보 등을 조회. 공식 메타데이터에서 무료·이용허락범위 제한 없음 확인 | 실제 API 호출, 요금 종류별 범위, 항로 커버리지와 적재는 미검증이다. 프로토타입의 요금 범위는 모두 예시값이다 |

KCCI 포함·제외 항목과 데이터셋 식별 근거는 [출처 검증 기록](04-verification-evidence.md)을 따른다. 기존에 공표운임으로 인용했던 15133134는 화물보안료산출정보로, 공표운임의 근거에서 제외했다.

## 용어 빠른 표

| 용어 | 뜻 |
|---|---|
| TEU / FEU | 20ft / 40ft 컨테이너 1개 |
| B/L | 선하증권. 선적했다는 증명서 |
| D/O | 화물인도지시서 (수입 쪽) |
| Incoterms (FOB, CIF 등) | 운송비를 누가 어디까지 내는지 정한 조건. FOB 수출이면 해상운임은 바이어가 낸다 |
| 장기운송계약 | 화주와 선사가 1년 단위로 운임을 고정하는 계약 |
